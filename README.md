# ShareIt

Сервис шеринга вещей: пользователи рассказывают, какими вещами готовы поделиться, и находят нужные вещи для аренды.

Этот модуль (ветка `add-controllers`) содержит каркас приложения и веб-слой для пользователей и вещей. Данные хранятся в памяти приложения.

## Технологии

- Java 21
- Spring Boot 3.3.2 (Web, Validation, Actuator)
- Maven
- Lombok

## Структура проекта

Код организован по фичам: всё, что относится к сущности, лежит в одном пакете.

```
ru.practicum.shareit
├── booking     — бронирование (модель, статус; контроллер и DTO в следующем спринте)
├── exception   — исключения и глобальный обработчик ошибок
├── item        — вещи: контроллер, сервис, хранилище, DTO, маппер
├── request     — запросы вещей (модель; контроллер и DTO в следующем спринте)
└── user        — пользователи: контроллер, сервис, хранилище, DTO, маппер
```

## REST API

### Пользователи

| Метод  | Путь             | Описание                           |
|--------|------------------|------------------------------------|
| POST   | `/users`         | Создать пользователя               |
| PATCH  | `/users/{id}`    | Обновить пользователя (частично)   |
| GET    | `/users/{id}`    | Получить пользователя              |
| GET    | `/users`         | Список пользователей               |
| DELETE | `/users/{id}`    | Удалить пользователя               |

### Вещи

Идентификатор пользователя передаётся в заголовке `X-Sharer-User-Id`.

| Метод | Путь                     | Описание                                                   | Заголовок          |
|-------|--------------------------|------------------------------------------------------------|--------------------|
| POST  | `/items`                 | Добавить вещь (пользователь становится владельцем)         | обязателен         |
| PATCH | `/items/{itemId}`        | Изменить название, описание, доступность (только владелец) | обязателен         |
| GET   | `/items/{itemId}`        | Просмотреть вещь (любой пользователь)                      | не требуется       |
| GET   | `/items`                 | Список вещей владельца                                     | обязателен         |
| GET   | `/items/search?text=...` | Поиск доступных вещей по названию и описанию               | не требуется       |

### Коды ошибок

| Код | Причина                                                        |
|-----|----------------------------------------------------------------|
| 400 | Ошибка валидации или отсутствует заголовок `X-Sharer-User-Id`  |
| 403 | Вещь редактирует не её владелец                                |
| 404 | Пользователь или вещь не найдены                               |
| 409 | Email уже используется другим пользователем                    |

Тело ошибки: `{"error": "описание"}`.
